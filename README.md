# map-quiz

# 白地図クイズ

地域ごとの白地図に付いた記号（A、B、C…）を見て、当てはまる国・地域の名前を答えるクイズです。ブラウザだけで動き、インストールやログインは不要です。

## アクセス方法

次のURLをブラウザで開いてください。

```
https://neighboury4.github.io/map-quiz/
```

パソコン、スマートフォン、タブレットのどれでも遊べます。

特定の地域を直接開きたい場合は、URLの末尾に地域ごとの記号を付けます。ブックマークしておくと、次回からその地域の問題をすぐに開けます。

```
https://（ユーザー名）.github.io/map-quiz/#east-asia
```

地域ごとの記号は、下の「収録している地域」の表を参照してください。

## 遊び方

1. トップページで、解きたい地域を選びます
2. 白地図が表示されます。出題される国・地域は色分けされ、それぞれに A、B、C… の記号が付いています
3. 回答欄の、記号ごとの入力欄に国・地域の名前を入力します
4. 「答え合わせ」を押します
   - 正解の国は、地図上と回答欄の記号の丸が緑になり、国の輪郭が緑の太線になります
   - 不正解の国は赤になり、回答欄の下に正しい名前が表示されます
   - 回答欄の下に「○問中○問正解」と表示されます
5. 「もう一度」を押すと、記号の割り当てが入れ替わり、最初からやり直せます
6. 「← 地域一覧へ」で、トップページに戻ります

### 答え方のルール

- 日本語と英語のどちらで答えても正解になります（例：「フィリピン」「Philippines」）
- 一部の別の表記も正解になります（例：「ビルマ」→ミャンマー、「グルジア」→ジョージア、「スワジランド」→エスワティニ）
- スペース、中黒（・）、ハイフン、アポストロフィ、アクセント記号の有無は区別しません（例：「サントメプリンシペ」「Cote d'Ivoire」も正解）

## 地図の見方

- **色**：出題する国・地域ごとに色を分けています。同じ色の島は、同じ国の領土です
- **灰色**：出題しない周辺の国・地域です
- **点線**：小さい国は、記号を国の外に出し、点線で国とつないでいます
- **この地図の範囲**：回答欄の上の小さな世界地図に、今見ている地図の範囲を黄色の枠で示しています

国の形は、手作業で描いた粗い簡略図です。実際の国境や海岸線とは細部が異なります。

## スマートフォンのホーム画面に追加する

iPhone・iPad の Safari で開き、「共有」→「ホーム画面に追加」を選ぶと、アプリのようにホーム画面から開けます。

## ファイル構成

| ファイル | 内容 |
|---|---|
| `index.html` | クイズ本体。地図のデータ、国名、判定の処理をすべてこのファイルに含んでいます |
| `icon.svg` | ブラウザのタブに表示するアイコン |
| `apple-touch-icon.png` | ホーム画面に追加したときのアイコン |

外部のライブラリ、APIキー、データベースは使っていません。

## 地域や国名を追加・修正するには

`index.html` の中の次の2か所を編集します。

- `REGIONS`：地域ごとの地図の図形と、記号の位置
- `NAMES`：国・地域のコードごとの、表示名と正解とみなす表記

正解とみなす表記を増やしたい場合は、`NAMES` の該当する国の配列に表記を追加してください。
